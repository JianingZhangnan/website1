# LAWS OF COMPOSITON

>[!def] law of combination
A *law of combination* on set $S$ is any rule for combining pairs $a,b$ of elements of $S$ to get another element, say $p$, of $S$. 
![[fig1.1|70%]]

Let an associative law of composition be given on a set $S$, then there is a unique way to define, for every interger $n,$ a product of $n$ elements of set $S$.

## Group and Examples

>[!def] group
>A *group* is a set $G$ together with a law of composition that has the following properties:
>1. The law of combination is associative: $(ab)c = a(bc)$ for all $a,b,c\in G$.
>2. $G$ contains an identity element $1$, such that $1a=a$ and $a1=a$ for all $a\in G$.
>3. Every element $a$ of $G$ has an inverse, an element $b$ such that $ab=1$ and $ba=1$.

>[!def] abelian group
>An *abelian group* is a group whose law of composition is commutative.

For example, the set of nonzero real numbers forms an abelian group under multipli
cation, and the set of alt real numbers forms an abelian group under addition. 

>[!def] order
>The *order* of a group $G$ is the number of elements that it contains, denoted by $|G|$

>[!example] some finite abelian groups
>- $\mathbf{Z}^{+}$: the set of integers with **addition** as its law of composition. *additive group of integers*.
>- $\mathbf{R}^{+}$: The set of real numbers with addition as its law of composition.  *Additive group of real numbers*.
>- $\mathbf{R}^{\times}$: The set of nonzero real numbers, with multiplication as its law of composition. *The multiplicative group*.
>- $\mathbf{C}^{+},\mathbf{C}^{\times }$.

>[!done] cancellation law
> $ab=ac\implies b=c,\quad ba=ca\implies b=c$ for all $a,b,c\in  G$

>[!notation] general linear group $GL_{n}$
>- The $n\times n$ *general linear group* is the group of all invertible $n\times n$ matrices denoted by $GL_{n}$. If we want to indicate that we are working with real or with complex matrices, we write $GL_{n}(\mathbf{R})$ or $GL_{n}(\mathbf{C})$
>- $SL_{n}(\mathbf{R})$ is the set of real $n\times n$ matrices $A$ with determinant to 1.

>[!notation] symmetric group $S_{n}$
>$S_{n}$ is the group of permutations of the indices $\mathbf{1,2,\dots,n}$.

There are $n!$ permutations of a set of n elements, so the symmetric group $S_{n}$ is a finite group of order $n$.

We describe the symmetric group $S_{3}$ next. This group, which has order six, serves 
as a convenient example because it is the smallest non-Abelian group.
