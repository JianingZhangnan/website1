# 11.4 习题

一、计算下列积分：
(1) $\int_{-1}^1 x^2 P_l(x) P_{l+2}(x) dx$,  
(2) $\int_{-1}^1 [x P_l(x)]^2 dx$,  
(3) $\int_{-1}^1 \ln(1-x) P_l(x) dx$  
(4) $\int_0^1 P_k(x) P_l(x) dx$.

二、将下列定义在 $[-1, 1]$ 上的函数用勒让德函数展开为广义傅里叶级数：
(1) $f(x) = x^4 - 3x^3$,  
(2) $f(x) = \begin{cases} x^2 & 0 \le x \le 1 \\ -x^2 & -1 \le x \le 0 \end{cases}$  
(3) $f(x) = \frac{x+|x|}{2}$,  
(4) $f(x) = \begin{cases} x & 0 \le x \le 1 \\ 2x & -1 \le x < 0 \end{cases}$

三、在半径为 $a$ 的球内 ($r < a$) 求下列定解问题：
$$\Delta u = 0,$$
$$\left. u \right|_{r=a} = \begin{cases} u_0 & 0 \le \theta < \alpha, \\ 0 & \alpha \le \theta < \pi. \end{cases}$$

四、在空心球壳内 ($a < r < b$) 求下列定解问题：
$$\Delta u = 0,$$
$$\left. u \right|_{r=a} = u_0, \quad \left. u \right|_{r=b} = u_0 \sin^2 \theta.$$

五、将下列函数按球函数 $Y_l^m(\theta, \varphi)$ 展开：
(1) $f(\theta, \varphi) = \sin^2 \theta \cos^2 \varphi$,  
(2) $f(\theta, \varphi) = (1 + \cos \theta) \sin \theta \cos \varphi$,  
(3) $f(\theta, \varphi) = \sin 3\theta \sin \varphi$,  
(4) $f(\theta, \varphi) = (\sin 2\theta)^2 \sin 2\varphi$.

六、半径为 $a$ 的均匀球体，表面温度为 $\left. u \right|_{r=a} = P_1^1(\cos \theta) \cos \varphi$。求球内稳定的温度分布。

七、在半径为 $a$ 的球内求下列泊松方程的定解问题：
$$\Delta u = A + Br^2 \sin 2\theta \cos \varphi,$$
$$\left. u \right|_{r=a} = 0.$$

八、半径为 $a$ 的热导体半球，底面温度恒定为 $0$，表面温度恒定为 $u_0$，求半球内稳定的温度分布
