# 第9章 分离变数法 习题（HW4）总览

## 解定解问题的系统流程（背这个）

1. **认方程 + 认坐标系**：波动 $u_{tt}=a^2u_{xx}$、热传导 $u_t=a^2u_{xx}$、位势 $\Delta u=0$；直角还是极坐标。
2. **预处理：化归到"齐次方程 + 齐次边界"**。三种非齐次各有套路，见 [[齐次化三套路]]。
3. **挑齐次方向**：哪个变量"方程齐次 + 两端[[边界条件类型#^def-homogeneous-boundary|边界齐次]]"，就对它做本征值问题 $X''+\lambda X=0$。
4. **解本征值问题**：得本征函数 $\{X_n\}$、本征值 $\lambda_n$，直接查 [[本征值问题速查表]]。
5. **展开 + 代回**：令 $u=\sum_n T_n(t)X_n(x)$，代回方程得每个 $T_n$ 的常微分方程。
6. **定系数**：用初始条件（或剩下那个边界）做傅里叶展开定 $T_n(0),T_n'(0)$。

> 极坐标位势方程的分离结果（欧拉方程 + 角向周期）单独成卡：[[极坐标拉普拉斯]]。

## 18 题按方法分类（导航）

**A 类·齐次方程 + 齐次边界（直接分离）**
- 二（波动，Dirichlet–Neumann）、四（热传导，Neumann–Dirichlet）、三（带阻尼 $u_t$ 项）。

**B 类·直角区域位势（二维拉普拉斯/泊松）**
- 五、六（方形 $\Delta u=0$，非齐次边界）、十一（方形泊松 $u_{xx}+u_{yy}=-1$）。

**C 类·极坐标位势** → 用 [[极坐标拉普拉斯]]
- 七（圆环 $\Delta u=0$）、九（半圆盘）。**注：八虽在圆环里，但方程带源项是泊松方程**（题面误印"拉普拉斯"），归 D 类，见 [[题08-圆环泊松]]。

**D 类·非齐次方程（含源项）** → 本征函数展开法，见 [[齐次化三套路]] 套路 A
- 十、十二、十三、十四、十五。

**E 类·非齐次边界含时间 $t$** → 辅助函数凑边界，见 [[齐次化三套路]] 套路 C
- 十六、十七、十八。

**物理建模**：一（两端固定琴弦三角形初位移，自己写定解问题 → 化成第二题那类）。
