# 符号约定

| 符号 | 含义 |
|---|---|
| $\eta$ | 序参量（空间均匀时的常数值）$=\langle\varphi\rangle$ |
| $\varphi(\mathbf r)$ | 序参量场（允许逐点变化） |
| $\delta\varphi$ | 涨落 $=\varphi-\eta$ |
| $h$ | 与序参量共轭的外场 |
| $t$ | 约化温度 $(T-T_c)/T_c$ |
| $a,b$ | 朗道系数，$a=a_0t$，$b>0$ |
| $c$ | 梯度项系数 |
| $G(\mathbf r)$ | 关联函数 $\langle\delta\varphi(0)\,\delta\varphi(\mathbf r)\rangle$ |
| $\xi$ | 关联长度 |
| $\chi$ | 磁化率 |
| $\alpha,\beta,\gamma,\delta,\nu$ | 临界指数 |
| $\tilde\eta$ | 反常标度指数（文献记 $\eta$，此处改记以避与序参量撞名） |
| $d$ | 空间维度 |

## 序参量的两种写法

朗道理论假设系统空间均匀，序参量是一个数 $\eta$，自由能是它的函数 $f(\eta)$。金兹堡–朗道允许序参量逐点变化，序参量是场 $\varphi(\mathbf r)$，自由能是泛函 $F[\varphi]$。两者关系

$$\varphi(\mathbf r)=\eta+\delta\varphi(\mathbf r),\qquad \eta=\langle\varphi\rangle .$$

高温无序相 $\eta=0$，低温有序相 $\eta\neq0$。

## 系综平均

$$\langle X\rangle=\frac1Z\sum_{\text{构型}}X\,e^{-F/k_BT},\qquad Z=\sum_{\text{构型}}e^{-F/k_BT}.$$

是按构型概率加权的期望，不是函数内积。

## 物理映射

铁磁体：$\eta\equiv M$（磁化强度），$\varphi\equiv M(\mathbf r)$，$h\equiv H$（外磁场）。液气临界点：$\eta\equiv\rho_l-\rho_g$。
